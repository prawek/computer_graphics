# Аффинные преобразования 2D и 3D

`affine.py` использует однородные координаты и матрицы NumPy: 3×3 для 2D, 4×4 для 3D. Для строкового вектора применяется `point @ matrix.T`. Перенос хранится в последнем столбце матрицы. Преобразования выполняются относительно начала координат; для вращения около центра нужно сначала перенести центр в начало, повернуть и вернуть обратно.

- `rotate2D`, `rotate3D`: поворот, угол в радианах.
- `shift2D`, `shift3D`: перенос.
- `scale2D`, `scale3D`: независимый масштаб по осям.
- `reflect2D`, `reflect3D`: отражение относительно координатной прямой или плоскости на заданном расстоянии `line`.

Сохранена нумерация старого API: в 3D `axis=1` означает Z, `axis=2` — X, `axis=3` — Y. В 2D отражение с `axis=1` идёт относительно `y=line`, с `axis=0` — относительно `x=line`. Поворот использует правую систему координат. Из-за направления экранной Y вниз положительный 2D-угол выглядит как поворот по часовой стрелке.

2D-функции принимают списки векторов `[x, y, 1]`, включая прежнюю форму `[[x, y, 1]]`. 3D-функции принимают и возвращают `Point3`; `to_numpy` и `to_point3` переводят представления. Дробные значения сохраняются до растеризации. Время — `O(n)` по числу точек.

Запуск: `python main.py --demo transform2d` или `--demo transform3d`. Во втором примере куб показывается в ортографической проекции.
