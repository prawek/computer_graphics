# Кирус — Бек

`cyrus_beck.py` отсекает отрезок произвольным выпуклым многоугольником. Отрезок задаётся как `P(t) = A + t(B − A)`, где `0 ≤ t ≤ 1`. Каждое ребро задаёт внутреннюю полуплоскость и ограничивает нижнюю или верхнюю границу параметра t. Если интервал пуст, видимой части нет.

`clip_segment(a, b, vertices)` определяет направление обхода по знаку площади и выбирает внутренние нормали. Вершины можно передавать по часовой стрелке или против неё. Параллельное ребро отбрасывает отрезок только тогда, когда он лежит снаружи; иначе проверка продолжается. Касание вершины возвращает совпадающие концы. Полностью невидимый отрезок возвращает `(None, None)`.

Вход проверяется на выпуклость, вырожденность и совпадающие соседние вершины. Проверка всех полуплоскостей занимает `O(n²)`, само отсечение — `O(n)`. Результат сохраняет дробные координаты. `Polygon(vertexes).cyruse_beck(a, b)` оставлен для совместимости и использует собственные вершины объекта.

Запуск: `python main.py --demo clipping`. Слева исходные отрезки, справа только их видимые части.
