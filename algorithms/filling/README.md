# Заливки

## Сканирующая строка ET/AEL

`scanline.py`: `scanline_fill(vertices, size=None)` группирует рёбра по первой строке пересечения (Edge Table). На каждой строке обновляется список активных рёбер (Active Edge List), пересечения сортируются по X и объединяются попарно по правилу чётности. Между строками X меняется на обратный наклон ребра.

Горизонтальные рёбра пропускаются. Строка проходит через центр пикселя, а ребро активно на полуоткрытом интервале Y: это исключает двойной учёт общей вершины. Интервалы X также полуоткрытые. Поддерживаются невыпуклые контуры; для самопересечений действует правило чётности. `size=(width, height)` ограничивает расчёт холстом. `fill2D` — совместимое имя той же функции.

Затраты: построение таблицы `O(E)`, сортировка активных рёбер на каждой строке и `O(S)` на формирование S пикселей. Возвращаемый список сам занимает `O(S)` памяти.

## Заливка с затравкой BFS

`flood_fill.py`: `flood_fill(image, seed, color)` заменяет цвет четырёхсвязной области, содержащей затравку. В очереди `deque` лежат соседние пиксели. Пиксель помечается до добавления в очередь, поэтому повторно не ставится. Время и худший расход очереди: `O(S)`. Рекурсии нет.

## Интервальная заливка

`span_fill(image, seed, color)` ищет от затравки полный горизонтальный интервал, закрашивает его и добавляет по одной затравке на непрерывную область выше и ниже. На обычных сплошных областях стек меньше попиксельной очереди. Худшая сложность по площади остаётся `O(S)`.

Обе затравочные функции меняют изображение на месте и возвращают число изменённых пикселей. Сравнение цвета точное, сглаженный или разорванный контур может пропустить заливку. Затравка снаружи холста или совпадающий цвет дают 0. При выборе затравки снаружи замкнутого контура заполняется фон.

Запуск: `python main.py --demo fill_compare`. Пример сравнивает BFS, Span и AEL на острове Минковского. Время включает формирование результата, без вывода на экран. Разница в числе пикселей возможна из-за того, что BFS/Span сохраняют нарисованный контур, а AEL применяет геометрическое правило центра пикселя.
