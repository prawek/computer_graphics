# EAN-13

`ean13.py` содержит генератор, контрольную цифру, кодирование и чтение горизонтального штрихкода.

`checksum(digits12)` суммирует первые 12 цифр с чередующимися весами 1 и 3. Контрольная цифра дополняет сумму до числа, кратного 10. `normalize_code` принимает ровно 12 или 13 ASCII-цифр: добавляет контрольную либо проверяет уже введённую. Ошибочный ввод не обрезается и не дополняется нулями.

`encode_bits` формирует 95 модулей: начальный маркер `101`, шесть цифр L/G, центральный `01010`, шесть цифр R и конечный `101`. Первая цифра определяет чётность L/G левой половины. `generate` рисует модули без сглаживания и добавляет белые поля. `decode_bits` выполняет обратное преобразование с проверкой маркеров, чётности и контрольной суммы.

`pipeline_mask` повторяет схему из источника: Собель → Гаусс 5×5 → порог 50 → XOR открытия и закрытия. Используются обычные бинарные операции из каталога морфологии.

`analyze(image)` использует строки маски как кандидатов, затем проверяет строки по высоте изображения. В каждой строке выделяются серии чёрного и белого; кандидат EAN-13 имеет 59 серий. По ширине 95 модулей оценивается масштаб, проверяются защитные серии, значения считываются в центрах модулей. Проверяются оба направления чтения. Кандидат принимается только при правильной контрольной цифре.

Возвращается `BarcodeResult`: строка кода, прямоугольник `(left, top, right, bottom)` с исключёнными правой и нижней границами, строка сканирования и копия изображения с разметкой. Изображение-источник не меняется. Если код не найден, поднимается `ValueError`.

Чтение рассчитано на чёткие горизонтальные полосы примерно одинаковой ширины модуля. Оно не исправляет поворот, перспективу и сильное размытие; это учебный декодер, а не универсальный сканер фотографий. Маска помогает поиску, но на сложном фоне сама по себе не гарантирует правильную локализацию. Основные затраты маски — линейные по площади изображения при фиксированных ядрах, сканирование — по числу выбранных строк и их ширине.

Запуск: `python main.py --demo ean_decode`. По умолчанию используется `5901234123457`; можно ввести свои 12/13 цифр или открыть изображение. Код и результат проверки появляются в окне.
