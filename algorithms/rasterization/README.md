# Брезенхем: отрезок и окружность

`bresenham.py` строит список пикселей вручную. `draw_line(x1, y1, x2, y2)` накапливает ошибку между идеальным отрезком и выбранной строкой пикселей. При превышении порога смещается вторая координата. Для крутых наклонов X и Y меняются местами; обратное направление восстанавливается в результате. Работают все октанты, вертикальный отрезок и точка. Время и память списка: `O(max(|dx|, |dy|))`.

`draw_circle(cx, cy, radius)` использует решение в средней точке. Достаточно рассчитать один октант и добавить восемь симметричных точек. Дубликаты удаляет множество. Радиус — целое неотрицательное число; радиус 0 даёт центр. Расчёт требует `O(radius)` шагов; сортировка результата делает порядок точек воспроизводимым.

`draw(image, points, color)` округляет координаты и пропускает пиксели за пределами холста. Исходное изображение меняется на месте. Отрезок включает оба конца.

Демонстрации: `python main.py --demo line` и `python main.py --demo circle`. Для отрезков справа показывается увеличенный растр, для окружности можно менять радиус.
