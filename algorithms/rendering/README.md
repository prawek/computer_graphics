# Глубина и освещение

## Z-буфер

`z_buffer.py`: `get_plane(a, b, c)` находит коэффициенты плоскости `Ax + By + Cz + D = 0` через векторное произведение двух рёбер. `fill3D(vertices, size=None)` получает пиксели построчной заливкой и вычисляет глубину в их центрах. Грани должны быть плоскими, а первые три вершины задавать плоскость. Грань, видимая ребром (`C≈0`), не растеризуется.

`update_buffer(points, buffer, width=800)` записывает минимальную Z в плоский массив глубины; меньшее Z ближе. Для нового размера холста ширину нужно передать явно. Начальное значение — `float('inf')`. `draw_buffer(image, points, buffer, color)` рисует только видимые пиксели. В демонстрации сначала рассчитываются глубины всех граней, затем цвета: результат не зависит от порядка рисования граней с различной глубиной. При равных глубинах цвет определяется последней нарисованной гранью.

Размер буфера — `width × height`. Запись за границы холста пропускается. Стоимость обработки — `O(S)` по числу растеризованных пикселей; память буфера — `O(width × height)`.

## Ламберт и Фонг

`lighting.py`: диффузная составляющая равна `max(0, N·L)` для единичных нормали и направления к свету. Зеркальная составляющая Фонга использует отражённый вектор `R = 2(N·L)N − L` и степень `max(0, R·V)^shininess`. По умолчанию `shininess=32`. Направление на наблюдателя вычисляется от текущей точки, а не от начала координат.

Нулевые направления дают нулевой вклад. Свет с обратной стороны не создаёт блик. `draw_light` проверяет Z-буфер, добавляет небольшой фоновый свет и ограничивает RGB диапазоном 0…255. Для двусторонних демонстрационных граней нормаль разворачивается к камере; функция `diffuse_light` использует переданную нормаль без изменения.

Запуск: `python main.py --demo zbuffer`, `--demo lambert`, `--demo phong`. В световых сценах можно менять X источника света.
