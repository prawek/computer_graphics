# Реализации

Каждый тематический каталог содержит функции алгоритмов и свой `README.md` с описанием сути и принятых правил. Эти модули не зависят от Tkinter и не читают или сохраняют файлы при импорте.

`geometry.py` определяет `Point2(x, y)` и `Point3(x, y, z)`. Отсечение и 2D-заливка принимают как такие точки, так и пары координат. В растре начало координат находится слева сверху, X направлен вправо, Y вниз. Глубина Z возрастает от наблюдателя. Для заполнения используются центры пикселей `(x + 0.5, y + 0.5)`.

Аффинные преобразования считают координаты без округления. Растеризация переводит их в целые координаты при отрисовке. Общие типы импортируются из `algorithms.geometry`, функции — из тематических пакетов. `demos.py` содержит сцены для общего окна; проверки находятся в `tests/`.
