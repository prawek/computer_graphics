# Пространственные фильтры

`spatial.py` реализует корреляцию с ядром через срезы NumPy. Готовые `ImageFilter` или OpenCV не вызываются. Каждый элемент ядра умножает соответствующий сдвиг массива. На границах повторяется ближайший пиксель (clamp-to-edge). Расчёт идёт в `float`, результат округляется и ограничивается 0…255. Входное изображение не меняется.

| Функция | Суть |
| --- | --- |
| `box_blur(image, kernel_size)` | Равномерное среднее по квадратному окну |
| `gaussian_blur(image, kernel_size, sigma)` | Вес `exp(−(x²+y²)/(2σ²))`, сумма весов нормируется к 1 |
| `sobel(image)` | Градиенты с весами 1, 2, 1 |
| `prewitt(image)` | Градиенты с одинаковыми весами трёх строк |
| `scharr(image)` | Градиенты с весами 3, 10, 3 |
| `laplacian(image)` | Модуль отклика ядра `[[0,1,0],[1,−4,1],[0,1,0]]` |
| `bin_filter(image)` | Модуль отклика ядра `[[1,−1],[−1,1]]` |
| `binarize(image, threshold)` | Среднее RGB строго больше порога даёт 255, иначе 0 |

Градиентные операторы рассчитывают `sqrt(Gx² + Gy²)` независимо для цветовых каналов. Для ядра 2×2 начало окна смещено на один пиксель вверх и влево от текущего. Лаплас и 2×2 показывают модуль отклика, чтобы сохранить границы обоих знаков; в C++ источнике отрицательные значения обрезались до нуля.

Поддерживаются L, RGB и RGBA; альфа сохраняется без фильтрации. Другие режимы переводятся в RGB. Бинаризация возвращает L. Размер сглаживающего ядра — положительный нечётный, сигма — конечная и больше нуля. Сложность прямого расчёта: `O(width × height × kernel_size²)`.

`sobel_filter(flat_pixels, width, height)` поддерживает старый интерфейс и возвращает плоский список яркостей. В отличие от прежней версии соседние строки индексируются как строки двумерного массива.

Запуск: `python main.py --demo gaussian` или другой фильтр из `python main.py --list`. Встроенный пример содержит шум, фигуры и тонкие полосы; можно открыть своё изображение.
