# Остров Минковского

`minkowski.py`: `minkowski_island(iterations, origin, side)` начинает с квадрата. Каждое его ребро заменяется ломаной из восьми сегментов длиной в четверть ребра. Выступ и впадина имеют одинаковую площадь, поэтому геометрическая площадь острова сохраняется.

В локальных координатах исходного ребра начала восьми сегментов: `(0,0), (1,0), (1,−1), (2,−1), (2,0), (2,1), (3,1), (3,0)`; конец последнего — `(4,0)`. Перпендикуляр к ребру позволяет применить одну схему к любому направлению.

После k итераций получается `4 × 8^k` вершин, а периметр удваивается на каждом шаге. Время и память — `O(8^k)`. Функция допускает 0…5 итераций, интерфейс ограничен четырьмя: на конечном растре более мелкие детали перестают различаться. Геометрическая площадь постоянна, число закрашенных пикселей зависит от разрешения и правил растеризации.

Вершины возвращаются без повторения первой в конце. Контур замыкается при рисовании. Генератор реализован по описанию в README C++ репозитория: в изученных исходниках отдельной реализации фрактала не было.

Запуск: `python main.py --demo minkowski`. Тот же контур используется в `--demo fill_compare`.
