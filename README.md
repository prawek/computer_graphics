# Алгоритмы компьютерной графики

Учебные реализации на Python и общая оконная демонстрация.
```powershell
python -m pip install -r requirements.txt
python main.py
```

На Windows можно использовать уже созданное окружение:

```powershell
.\.venv\Scripts\python.exe main.py
```

Нужны Python 3.10+, Pillow, NumPy и Tkinter. В обычной установке Python для Windows Tkinter входит в комплект; в Linux может потребоваться системный пакет `python3-tk`.

## Работа с демонстрацией

Выберите алгоритм в дереве слева. В центре показаны исходные данные и результат с сохранением пропорций. Под изображениями находятся время расчёта и пояснения к сцене. Размер окна можно менять.

Параметры меняются стрелками числового поля; после ручного ввода нажмите **Enter** или **Пересчитать**. Кнопка **Встроенный пример** возвращает исходные параметры. Для заливок BFS и Span щелчок по левому изображению задаёт затравку. Щелчок снаружи контура закрасит внешнюю область: это ожидаемое поведение затравочного алгоритма.

Фильтры, морфология и чтение EAN-13 принимают своё изображение через **Открыть изображение…** или **Ctrl+O**. Для отзывчивости учебной демонстрации большие изображения уменьшаются в памяти до 1280×960 с сохранением пропорций; это отражается в строке состояния. Файл на диске не меняется. Сами функции алгоритмов принимают изображения любого размера.

Кнопка **Описание реализации** открывает Markdown соответствующего каталога прямо в приложении. **Esc** закрывает главное окно. Вычисления идут в рабочем потоке; смена алгоритма и изменение размера окна остаются доступны во время расчёта.

Можно сразу открыть определённый пример:

```powershell
python main.py --demo fill_compare
python main.py --demo gaussian --image images/example.png
python main.py --list
```

`main.py` содержит интерфейс, `algorithms/demos.py` — воспроизводимые сцены, `algorithms/geometry.py` — общие типы точек. Алгоритмы можно импортировать отдельно, без открытия окна.

В корне из Python-файлов находится только `main.py`. Реализации и сцены собраны в `algorithms/`, проверки — в `tests/`. Например, отрезок импортируется как `from algorithms.rasterization import draw_line`, а демонстрация Собеля запускается командой `python main.py --demo sobel`. Описания реализации находятся в Markdown-файлах; комментарии и строки документации из Python-кода удалены.

## Проверки

```powershell
python -m unittest discover -v
```

Проверяются октанты и связность линий, симметрия окружностей, граничные случаи отсечения, невыпуклая заливка, совпадение BFS и Span, двумерная свёртка, морфология, матрицы преобразований, глубина, контрольная цифра EAN-13 и все демонстрационные сцены. Для этих проверок дисплей не нужен.

При доступной графической сессии можно дополнительно проверить обработчики окна: `python -m tests.gui_smoke`. Проверка проходит по всем сценам, меняет параметры и затравку, проверяет своё изображение, окно описания и быструю смену алгоритмов.
